> 填不出来的项写「默认」或「待定」即可，不要留空导致歧义。

## 4. 视图与交互 ✅ / ⚙️

### 4.1 默认视图

- 桌面默认：`月` / `周`（现在 `defaultView` 一项同时管桌面和移动端）
- 移动端默认：`周` / `月` / `与桌面相同`
  - 若要「桌面月、移动端周」，需要新增 `mobileView` 配置 ⚙️

### 4.2 展开状态（⚙️ 默认值目前都是「收起」）

- 月视图首次进入：收起（5 行铺满）/ 展开（显示当天全部场次）⚙️
- 周视图首次进入：7 天 / 展开（桌面 4 天、移动端 2 天）⚙️

### 4.3 尺寸（⚙️ 目前写死）

- 周视图展开天数：桌面 `____` 天 / 移动端 `____` 天（当前 4 / 2）⚙️
- 月视图收起时行数：`____` 行（当前 5）⚙️
- 周视图时间轴上下留白：`____` 小时（当前前后各 1 小时，按全场次动态取整）⚙️

### 4.4 筛选与交互

- 影厅筛选范围：只筛日历（当前）/ 日历 + 已选列表 ⚙️
- 周视图左右翻页：按可见天数（当前）/ 按整周 ⚙️
- 时间冲突提示：显示 message（当前）/ 不提示 ⚙️
- 是否允许逐场改描述、改行程：允许（当前）/ 不允许 ⚙️

### 4.5 判断题（对 ✔ / 错 ✘）

| 判断 | 你的答案 | 影响 |
| --- | --- | --- |
| 同一天会有多个厅同时放映 |  | 需要影厅筛选 + 并排分列 |
| 同一天场次时间可能重叠 |  | 周视图按重叠簇分列 |
| 需要按厅筛选 |  | 显示筛选下拉 |
| 同一影片会排多场 |  | 同标题联动高亮、同片场次 |
| 有映后交流 / 讲座 / 导赏等活动场 |  | 活动标签 + 前缀图标 |
| 需要显示票价 |  | ⚙️ 需要新增票价字段 |
| 需要显示评分 / 评价人数 |  | 详情显示、导出不带 |
| 需要生成订阅头日程 |  | `kind: "header"` |
| 需要二维码 |  | 生成 `qrcode/<id>.svg` |
| 数据会频繁加场 / 改期，场次 id 必须稳定 |  | 使用数据源 id，不用时间生成 |
| 移动端和桌面可以用同一个默认视图 |  | 否则需要 `mobileView` ⚙️ |
| 希望这个日历有自己的 logo / 主视觉 |  | ⚙️ 需要 per-calendar logo |
| 导出文件不要带票价 / 评分 |  | 当前默认就不带 |
| 日历名称和场地名称不同（如资料馆 vs 小西天） |  | 分别填 `name` / `venue` |

## 9. 我拿到问卷后会做什么

1. 读答案，把缺失项列出来问你（只问真正影响结果的）。
2. 生成 / 更新 `src/data/raw/<id>.raw.json`；如有数据源，补一个导入脚本。
3. `pnpm gen` 生成显示配置、`public/subscribe/<id>.ics`、`public/qrcode/<id>.svg`。
4. 实现你勾选的 ⚙️ 配置项（按日历生效，不影响已有日历）。
5. `pnpm typecheck` / `pnpm build`，用真实浏览器截图核对桌面 + 移动端。
6. 把「与现有日历的差异」列给你确认。
