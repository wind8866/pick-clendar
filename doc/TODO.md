## 配色口径

风格万相（`#E5CEA8` / `#6A3424` / `#9AB9AF`）的主色约 **S≈49% / L≈28%**；
资料馆原先的 `#EE3E36` 是 **S≈84% / L≈57%**，饱和度和亮度都高，红色因而“跳出来”。

统一口径：主色只负责点亮、聚焦、提醒、交互，饱和度 / 亮度对齐风格万相的主色深度；
背景沿用同一饱和度但大幅提高亮度，避免纯白或高饱和粉底。于是：

| 日历 | 背景 | 主色 | 协助色 |
| --- | --- | --- | --- |
| 青岛 | `#E5CEA8` | `#6A3424`（H14 / S49 / L28） | `#9AB9AF` |
| 北京 | `#F6EAE2`（H24 / S53 / L93） | `#6D2E27`（H6 / S47 / L29） | `#C1AD86` |
| 江南 | `#F3F1E7`（H50 / S33 / L93） | `#3A7133`（H106 / S40 / L31） | `#AFC0A2` |

厅色是独立的身份色，不参与主题派生，只画在日程左侧 3px 竖线与筛选下拉标记上。
